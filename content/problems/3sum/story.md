## Situation

Friends sit around a campfire, each holding a lantern with a glow value, some negative: **−1, 0, 1, 2, −1, −4**. A trio balances the fire when their glows add up to exactly zero.

## Goal

List every different trio of glow values that adds up to zero.

## Rules

- A trio uses three different friends.
- Two trios with the same three values count once.
- The order of trios in the answer does not matter.

## Worked example

**(−1, −1, 2)** and **(−1, 0, 1)** both balance the fire. Using a different −1 friend gives the same values, so it is not listed again.

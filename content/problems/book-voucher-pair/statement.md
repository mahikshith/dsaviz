Given an integer array `prices` sorted in [[nondecreasing]] order and an integer `target`, return the [[zero-based-index|zero-based]] indices `[i, j]` with `i < j` and `prices[i] + prices[j] == target`. If no such pair exists, return `null` (`None` in Python).

- The same index may not be used twice. Equal values at different indices are allowed.
- Do not modify `prices`.
- If several pairs work, any one of them is accepted.
- In the interactive player: at most 12 prices, each from 0 to 999, and a target from 0 to 1998.

Given an integer array `visitors` and an integer `k` with `1 ≤ k ≤ len(visitors)`, find the [[subarray]] of exactly `k` consecutive elements with the largest sum. Return `(start, total)`: the [[zero-based-index|zero-based]] index where it starts and its sum. If several subarrays share the largest sum, return the smallest `start`.

- Do not modify `visitors`.
- The sliding-window method also works with negative values; only this story's data is non-negative.
- In the interactive player: 1 to 12 values, each from 0 to 999.

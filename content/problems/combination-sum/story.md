## Situation

A shop sells items priced **2, 3, 6 and 7**, as many of each as you like. You want to spend exactly **7**.

## Goal

Return every different basket of items whose prices add up to exactly the target.

## Rules

- Any item can be used any number of times.
- Baskets with the same items in a different order count once.
- All prices are positive and different.

## Worked example

**2 + 2 + 3** and **7** both cost exactly 7.

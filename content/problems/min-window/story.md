## Situation

A street market has stalls in a row, each selling one item, labelled **A D O B E C O D E B A N C**. Your shopping list says **A, B, C**.

## Goal

Find the shortest run of neighbouring stalls that sells everything on the list, as many times as the list asks for.

## Rules

- The run must be consecutive stalls.
- If the list repeats an item, the run must contain it that many times.
- If no run works, the answer is empty.

## Worked example

The run **BANC** has an A, a B and a C and is only 4 stalls long. Longer runs, such as ADOBEC, also work but are not the shortest.

Given the root of a binary tree, return whether it is a valid [[binary-search-tree|binary search tree]]: every node's left subtree holds only smaller values, its right subtree only larger values, and both subtrees are valid too.

- Trees are written in level order: `[4, 2, 7, 1, 3]` lists nodes floor by floor, left to right, with `null` for a missing child.

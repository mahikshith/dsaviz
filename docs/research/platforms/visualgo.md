# VisuAlgo (visualgo.net) - platform research

## Method
- Tool: REA MCP `capture_browser_scenario` (launch mode, Edge, DOM capture), date 2026-10-24.
- robots.txt read with REA: `User-agent: *` / empty `Disallow:` = everything allowed. No bot check, CAPTCHA, or rate limit seen. (Order note: the first 3 page captures ran just before the robots check; robots turned out fully open.)
- Pages captured: `/en` (home), `/en/sorting`, `/en/bst`, `/en/dfsbfs`, `/training`, plus stylesheet `/css/common-1.0.2.css`. About / Team / Terms / Privacy overlays are embedded in each page and were read from there.
- Not logged in anywhere. Login, Tests mode, Profile skipped.
- Caveat: the animation runs in JS after a click; REA captured static DOM, so the colour legend and exact frame timing come from slide text and control markup, not from watching frames.

## Summary and business model
- Free university project: conceived 2011 by Assoc. Prof. Steven Halim (NUS School of Computing), built with student researchers; funded by an NUS CDTL grant, then Optiver donations (stated as continuing to mid 2026 and possibly beyond). No ads, no paywall, no analytics (Google Analytics dropped Aug 2023).
- Audience: NUS courses (CS1010, CS2040/IT5003, CS3230, CS3233, CS4234) plus the wider world. Free self-created accounts store layout, speed and language; NUS accounts let lecturers track e-lecture reading and quiz progress. Lecturer accounts see hidden answer slides and the Hard quiz setting.
- Trilingual: /en, /zh, /id.
- Home text claims "24 visualization pages"; the live home grid shows 26 tiles (listed below).

## Sitemap and URL patterns
- `/en` home: grid of module tiles, search box with tag chips, "Do You Know?" random tip, About/Team/Terms/Privacy overlays.
- `/en/<module>` visualizer (e.g. `/en/sorting`, `/en/bst`, `/en/avl` alias, `/en/dfsbfs`). `?slide=11-4` deep-links one e-lecture slide. `/en/<module>/print` is the printable lecture text.
- `/training` (+ `?module=<m>&diff=Medium&n=7&tl=0`) online quiz; `/tests` NUS exam mode; `/login`, `/profile`, `/statistics` (translation stats).
- Language prefix swap (`/zh/`, `/id/`).

## Features and how they work
**Two modes per page.** E-Lecture Mode (default for first-time visitors): a numbered slide deck (80+ slides on Sorting) beside the visualization; readout "slide 1 (1%)", prev/next arrows, a dropdown outline of numbered sections (Sorting has 20 sections incl. a Big-O primer, each algorithm with pseudocode and analysis, mini quizzes, extras with online-judge links). Exploration Mode (toggle with Esc): lecture hides and the action menu is the focus.

**Visualizer controls (from DOM ids and slide text):**
- Algorithm switcher in the top bar: 3-letter abbreviations (BUB/SEL/INS/MER/QUI/R-Q/COU/RAD on Sorting; tabs "Binary Search Tree | AVL Tree" on BST). Active algorithm is randomized on each page load.
- Bottom-left Actions menu (collapsible): Create (random, sorted asc/desc, nearly sorted, many duplicates, or user-typed list with a Go button; array-size field; base setter for radix/counting) and Execute (Sort, Search(v), Insert(v), Remove(v)...). Graph pages: Edit Graph (draw), Input Graph (edge list / adjacency list / matrix with auto layout), Example Graphs.
- Status panel with a one-line narration per step, and a code-trace panel (pseudocode with the executing line highlighted). Both collapsible.
- Media bar: go-to-beginning, previous frame, play/pause (replay at end), next frame, go-to-end, a draggable progress bar to scrub, and a speed slider (readout "1.0x").
- Keyboard: Space play/pause/replay; Left/Right step back/forward; `-`/`+` speed; PageUp/PageDown previous/next slide; Esc toggle mode; F11 full screen.
- Per-module extras: show/hide recursion depth (Sorting), simple/stable variants of counting sort, tree height readout (`N=9, h=3` on BST).
- Mobile lite version (since Apr 2022): overlay rewind/play/forward buttons and a rotate-device prompt; desktop designed for 1366x768 or larger.
- Share overlay, "Open in Browser", embed status field.

**Animation model.** The operation is run to completion first, producing a list of frames; the media bar scrubs that list, so stepping backward and dragging progress both work. Vertex/edge colour carries state, small red text under a vertex shows changed values, sorting uses bars. Drawn with d3 7.3 (plus d3-force-boundary for graph layout), jQuery and jQuery-UI sliders.

**Quiz system.** `/training`: choose any subset of modules, difficulty (Easy/Medium/Hard), number of questions, time limit (none, 5 to 40 min). Questions are randomly generated by rules and graded server-side. Public access only through training mode. Small inline MCQs (radio + Submit) also sit inside lecture slides.

**Progress tracking:** only for logged-in users (per-slide read status, quiz history). Anonymous visitors get none.

## Content coverage (26 tiles)
- Linear: Array, Sorting (7 algorithms: Bubble, Selection, Insertion, Merge, Quick incl. randomized, Counting, Radix), Bitmask, Linked List (with stack/queue/deque).
- Trees, heaps, hashing: Binary Heap, Hash Table, Binary Search Tree (+AVL), Union-Find DS, Fenwick Tree, Segment Tree, Recursion Tree/DAG.
- Graphs: Graph Structures, Graph Traversal (DFS/BFS plus topological sort, bipartite check, cut vertex and bridge, SCC both Kosaraju and Tarjan, 2-SAT), Min Spanning Tree, SS Shortest Paths, Cycle Finding, Network Flow, Graph Matching, Min Vertex Cover, Steiner Tree, Traveling Salesperson, NP-complete Reductions.
- Strings and geometry: Suffix Tree, Suffix Array, Geometry (Polygon), Convex Hull.
- Lecture depth: Sorting 20 sections, BST 15 sections (three remove cases, AVL rotations, height bounds), DFS/BFS 13 sections (analogies, hands-on trace, O(V+E), cycle detection, topo sort).
- Slugs: array, sorting, bitmask, list, heap, hashtable, bst, graphds, ufds, fenwicktree, segmenttree, recursion, dfsbfs, mst, sssp, cyclefinding, suffixtree, suffixarray, polygon, convexhull, maxflow, matching, mvc, steinertree, tsp, reductions (all under `https://visualgo.net/en/`).

## Design language
Source: `common-1.0.2.css` and page markup.
- Fonts: PT Sans (body, 13px base), Silkscreen pixel font for the wordmark and overlay headings, Latin Modern Math for math, Courier New for code snippets. Bootstrap 5.0.2 + jQuery.
- Palette: page background `#eeeeee`; top and bottom bars `black` with white text; title tabs `#aaaaaa`, selected tab bold white; action chips `green`; consent popup `#0275d8` with 15px radius; Facebook login chip `#516eab`; overlay scrim `rgba(0,0,0,0.7)`.
- Components: flat dark 40px top bar with algorithm tabs, collapsible side panels (actions, status, code trace), slide cards with prev/next arrows, 2px-radius chips.
- Motion: step-driven, no decorative easing; the speed slider scales frame duration.
- Tone: academic, dense, friendly "pro-tip" call-outs.

## Adopt for DSAMaxxing
**P0**
- Frame-list animation with scrub bar plus step/prev/next/play/replay and a speed slider, all keyboard-bound (Space, arrows, +/-). Precompute the whole trace so stepping back is free.
- Pseudocode panel with live line highlight beside a one-line plain-language narration (our own wording).
- Colour is state: one fixed, labelled legend across every visualizer.
- Input box with presets (random, sorted, nearly sorted, many duplicates) and "your own list".
**P1**
- Deep-linkable step state in the URL so a pattern story can be shared and resumed.
- Short "predict the next state" check after an animation, generated from the trace.
- Guided story vs free-explore toggle (Esc), collapsible panels, lite layout for phones.
**P2**
- Auto-generated, auto-graded practice questions from the same trace engine.
- Printable story view per pattern.
- Anonymous local progress (steps seen) in localStorage.
